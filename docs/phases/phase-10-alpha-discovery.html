Alpha discovery — Phase 10

Five features, fifteen tests, zero survivors

A feature-level (not strategy-level) investigation into whether the existing market dataset contains any causal, out-of-sample, multiple-testing-corrected predictive relationship worth building a new strategy around. Five economically motivated features × three forward horizons = 15 pre-specified hypotheses, tested across the frozen 12-symbol Phase 8/9 universe. None survives Bonferroni correction. One feature (relative volume) shows a consistent-but-tiny, economically negligible pattern worth a narrow follow-up; the other four show no coherent signal, and one shows the textbook development-and-validation-agree/out-of-sample-reverses failure pattern.

5 features × 3 horizons = 15 hypotheses 0 survive Bonferroni correction (α=0.00333) 0 changes to strategy/, risk/, paper/, backtesting/, MCP 271/272 tests passing (1 pre-existing, unrelated) Classification: C (overall), B (one feature)
Bottom line

No feature reaches classification A. Four of five (trailing momentum, ATR-normalized volatility, mean-reversion z-score, relative strength vs. market) show no coherent, cross-symbol-consistent, out-of-sample-confirmed relationship to future returns at any tested horizon — classification C. The fifth (relative trading volume) is the one exception worth naming: its sign is consistent across development, validation, AND out-of-sample at the 20-bar horizon, with 7/12 symbols agreeing in OOS — but the effect size is tiny (pooled Spearman ρ ≈ 0.04), the quantile-bucket pattern is not monotonic, and it does not survive correction for the 15 hypotheses tested. Classified B — inconclusive, not rejected outright, but nowhere near strong enough to act on.

The most informative single result is atr_pct_of_price at the 5-bar horizon: development (ρ=+0.032, p=0.002) and validation (ρ=+0.070, p<0.001) both showed a real-looking positive relationship — and out-of-sample reversed sign entirely (ρ=−0.018, p=0.325). This is the exact "positive in development and validation, negative in OOS → classify as failed" pattern this phase's own methodology was designed to catch, and it did.

1Objective

Determine whether the existing market dataset contains ANY evidence of a causal, tradeable predictive relationship — testing FEATURES against future returns, not building or tuning a trading strategy. "No predictive signal found" was explicitly an acceptable outcome going in, and is substantially what was found.

Exactly 5 families, one feature each — within spec's "maximum 5" cap. ADX/trend-strength and higher-timeframe (weekly) confirmation were considered and explicitly excluded (not silently dropped): ADX has no existing implementation and building one purely for this test risked introducing a new, nontrivial indicator's own bugs under this phase's small-N constraint; weekly resampling risks a genuine current-week look-ahead trap that would need careful, separately-tested alignment logic.

5Target definitions

fwd_return_1  = close[T+1] / close[T] - 1
fwd_return_5  = close[T+5] / close[T] - 1
fwd_return_20 = close[T+20] / close[T] - 1

These are LABELS, not features — computed via research/alpha_features.py::add_forward_return_targets, which is the ONLY place in this phase's code that deliberately looks ahead (via shift(-h)), and is never called by, or fed back into, the feature-computation function. Maximum favorable/adverse excursion targets were considered and excluded to keep this phase's scope to the three horizons spec named as the minimum, rather than expanding an already-15-hypothesis experiment further.

6Causality methodology

  • Every feature is a pure rolling/trailing function of rows ≤ T (no negative shift, no full-dataset statistic).
  • The cross-sectional feature's market-index alignment uses forward-fill only (fills a gap using a PAST index value, never a future one).
  • Quintile bucket EDGES are fit ONLY on each symbol's development-period data, then applied unchanged to validation and out-of-sample rows — no bucket definition was ever informed by validation/OOS data (spec's explicit "any feature transformation learned from data must be fitted only on development").
  • Verified with 14 new permanent regression tests (tests/test_alpha_features.py) — truncated-history equivalence and mutate-the-future controls for all 5 features, plus a control case proving the harness can actually detect a real forward-looking dependency (so the causality tests aren't vacuously passing).

11Multiple-testing treatment

15 pre-specified hypotheses (5 features × 3 horizons) were tested — the complete tested universe, not a subset selected after the fact. Bonferroni correction: α = 0.05 / 15 = 0.00333. At the UNCORRECTED α=0.05 level, 5 of 15 pooled OOS tests show p<0.05 (roughly double the ~0.75 expected by chance alone under a true null, though nowhere near a strong departure from chance with only 15 tests). Zero of 15 survive the Bonferroni-corrected threshold. This experiment is exploratory, not confirmatory — any feature carried forward would need a dedicated, separately-pre-registered confirmation phase on fresh data, exactly as spec requires.

12Economic significance

Only volume_ratio shows anything resembling a stable directional pattern worth this check. Its OOS top-minus-bottom quintile spread at h=5 is +0.170 percentage points (0.250% − 0.080%) over a 5-day holding period. This is the ENTIRE gross edge available to exploit, before any cost is deducted — and it is not economically large: 0.17% over 5 trading days, before considering that the bucket shape isn't monotonic (§9), meaning even this number overstates what a real rule could reliably capture.

13Cost implications

Phase 8's baseline cost model (brokerage 20/fill + 5bps entry + 5bps exit) implies a round-trip cost of 10bps in slippage alone, plus a flat $20-per-fill brokerage that scales inversely with position size in percentage terms. A 0.17% gross edge is only ~7bps above the 10bps slippage floor before brokerage is even considered — for any position smaller than roughly $50,000 notional per trade, the flat brokerage alone would consume the remainder. This is not a promising economic magnitude to build a strategy around, independent of the statistical significance question already answered in §11.

14Leakage tests

14 permanent tests in tests/test_alpha_features.py, covering all 5 features: structural truncated-history equivalence, mutate-the-future controls (including mutating the market index series for the cross-sectional feature), a market_series=None degenerate case, a positive control proving the harness can detect a genuine forward-looking dependency, and a check that adding target/label columns never alters any feature column. All 14 pass.

15Reproducibility

The full pooled analysis was run twice against the (already-populated) local cache. Byte-identical output both times — no caveat, cache was confirmed warm before either comparison run (the lesson learned from Phase 8's first, improperly-controlled reproducibility attempt).

19Overall classification

C — no evidence of a durable, actionable predictive signal, with one narrow exception flagged B

None of the 15 pre-specified hypotheses survives correction for multiple testing. Four of five features show no coherent cross-symbol, out-of-sample pattern at all. The fifth (relative volume) is genuinely different in character — consistent sign across all three chronological periods and majority symbol agreement — but its effect size is smaller than the existing cost model's slippage floor alone, and its quantile shape is not monotonic. This does not meet the bar for classification A under any of spec's stated criteria (statistical significance after correction, non-trivial economic magnitude, and a coherent monotonic-or-otherwise-stable shape were all required and none was fully met).

20What this does NOT prove

  • This does not prove markets are unpredictable in general. It tests exactly 5 simply-defined features over 3 horizons on daily bars for 12 symbols — a narrow slice of the space of possible predictive relationships.
  • This does not prove volume_ratio has zero information content. "B — inconclusive" means exactly that: the evidence is too weak and too small in magnitude to act on, not proven to be pure noise. A dedicated confirmation study with a larger/different sample could still resolve this either way.
  • This does not test feature combinations. Spec explicitly scoped that out as Phase 11 territory to avoid replacing strategy-parameter overfitting with feature-selection overfitting.
  • This does not test intraday, alternative-data, or fundamental features — only what's derivable from the existing daily OHLCV pipeline.
  • A non-significant result is not the same as a proven absence of any relationship — it means this experiment did not detect one strong enough to distinguish from noise at this sample size, using these specific tests.

21Recommendation for Phase 11

Do not build a strategy around any of these 5 features individually — none reaches classification A. If Phase 11 proceeds, the only defensible path from this phase's evidence is a SEPARATELY pre-registered confirmation study of volume_ratio specifically (not a combination, not the other four) on data or symbols not used to generate this hypothesis, explicitly designed to resolve its B classification one way or the other before any entry/exit/sizing rule is specified around it. Absent that confirmation, the recommendation mirrors Phase 8's and Phase 9's: the platform's proven engineering correctness remains the validated deliverable of this research program; no strategy or feature discovered so far has cleared the bar for further investment.
