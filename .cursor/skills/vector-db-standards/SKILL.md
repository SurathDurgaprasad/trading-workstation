# Vector DB Standards

## Rules

- Separate embeddings from retrieval.
- Preserve metadata.
- Use deterministic IDs.
- Keep chunk sizes consistent.
- Avoid duplicate embeddings.
- Isolate retrieval logic.
- Keep vector stores replaceable.
- Support future providers.
