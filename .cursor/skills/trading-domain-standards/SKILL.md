# Trading Domain Standards

## Rules

- Never guarantee profits.
- Missing data should produce WAIT.
- Confidence must be numeric.
- Every decision requires reasoning.
- Preserve explainability.
- Avoid speculative conclusions.
- Risk analysis is mandatory.

## Allowed Decisions

- STRONG_BUY
- BUY
- WAIT
- SELL
- STRONG_SELL
